# UrbanAI-101

Welcome to **UrbanAI-101**: an open course on spatial statistics and urban analytics.

## Contents

This book covers:

- **Spatial statistics**: spatial autocorrelation, Moran's I, LISA, spatial weight matrices, and spatial dependence.

More chapters will be added over time.

## How to use this book

- Read online on GitHub Pages.
- Run code locally: clone the repo and install dependencies (see `requirements.txt`).
- Run interactively: use the Binder or "Live Code" button (if enabled) to open the notebooks in the cloud.
